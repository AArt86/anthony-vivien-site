Orphan Age

2024
studios : Black Flag / Ubisoft
Brain Up
Position : 

Visual development, UI Design


Project :

Orphan Age is a cyberpunk life sim game where you play as the children left behind.

I focused on creating screenshots to set the tone for the 2D/3D look. I also redesigned the UI to better match the style we were aiming for. Unfortunately, the project came to an end. We jumped in at the very last stage with Brain Up to try and revive it with a new art direction. But since the project had been running for a long time already, the investment wasn’t renewed, and they couldn’t push it further, even though it definitely had potential.
